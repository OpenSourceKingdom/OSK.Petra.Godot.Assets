# OSK.Petra.Godot.Assets

Provides access to instantiators, loaders, configuration, and more for an asset sytem within Godot that can be utilized with the [Petra Asset System](https://github.com/OpenSourceKingdom/OSK.Petra.Assets)

This library provides:
- Asset Manager and related configuration
- Simple load screen for background loading
- Asset instantiators for Node2D and Node3D
- Configuration for asset packages, collections, etc.
- Module loaders that utilize a [workflow](https://github.com/OpenSourceKingdom/OSK.Operations.Workflows) to load a module in a multi-step approach and provde feedback to a UI and player
